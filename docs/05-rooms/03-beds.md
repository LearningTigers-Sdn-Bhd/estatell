# Beds

## Purpose

Beds are the sellable units of a Bed room type (dorms).

## Data model

```
beds    id, room_id, label, position, archived_at, timestamps
        unique (room_id, label)
```

## Rules

- Beds exist only in rooms whose room type has `sell_unit = Bed`.
- Labels are generated by default (A1...A6) and can be edited.
- A booked bed is stored on `unit_nights.bed_id` (see [Reservation shape](../12-reservations/01-reservation-shape.md)).
- Availability for a Bed room type counts beds (see [Availability](../10-availability/01-availability-service.md)).
